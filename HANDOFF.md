- Stack: Vite, React, TypeScript, Motion, Three.js
- Hosting: DigitalOcean App Platform static site
- Source: <https://github.com/mrahmani-hash/midya-test-website>
- Branch: `main` (deploys automatically)

## Galaxy renderer

`src/components/GalaxyBackground.tsx` owns the Three.js lifecycle. It creates:

- Procedural spiral galaxy, outer star field, and animated star-flight layer
- Shader-based procedural nebula
- Dust, a planet, a Saturn-like planet, and original rings
- Pointer depth/parallax and restrained Unreal Bloom

It does not load textures or remote 3D assets.

### Adaptive quality

Full 3D remains on desktop and capable phones. The renderer selects a quality
profile using viewport size, device memory, hardware concurrency, and device
pixel ratio:

- Mobile/low power: lower DPR and star counts, 40 fps cap, reduced bloom
- Mid-tier: moderate DPR and particles, 55 fps cap
- High-tier: higher DPR and particles, 60 fps cap

Rendering pauses when the document is hidden. Reduced-motion users receive one
static 3D frame. The component disposes geometries, materials, post-processing,
the renderer, and its WebGL context on teardown. If WebGL creation or the
context fails, CSS supplies the fallback galaxy gradient.

## Local development

Node 22 or newer is expected.

```bash
npm ci
npm run dev
```

Quality checks:

```bash
npm run typecheck
npm run build
```

The compatibility wrapper used by previous deployment workflows still works:

```bash
./build.sh
```

It runs `npm ci` and `npm run build`.

## Social image generation

The generated images use original procedural stars, galaxy points, and planet
art. Pillow is required.

```bash
python3 scripts/generate-social-images.py
```

This rewrites the OG images, touch icon, and PNG favicons in `public/`. Bump the
`?v=` query in `index.html` whenever the social card changes.

## Rollback

The last pre-galaxy site is recoverable from commit `3595ad4`. Preferred
rollback:

1. Create a new branch from `main`.
2. Revert the galaxy redesign commit; do not force-push or hard-reset `main`.
3. Run the old build as documented in that historical revision.
4. Merge and let App Platform redeploy.

## Guardrails

- Keep WebGL headless during automated browser tests.
- Preserve mobile quality scaling, hidden-tab pause, reduced-motion behavior,
  fallback styling, and teardown disposal.
- Keep profile details centralized rather than duplicating them in components.
- Do not add unlicensed ships, branded fictional assets, or copied template
  code.
- Do not put secrets in this static site; none are needed for its build.
